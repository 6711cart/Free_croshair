# Free_croshair

Windows desktop crosshair editor and overlay.

## Download

Open the [latest release](https://github.com/6711cart/Free_croshair/releases/latest) and download `Free_croshair.exe`. Run the downloaded installer on Windows.

The installer is unsigned, so Windows SmartScreen may show a warning. The overlay is intended for windowed and borderless games; compatibility is not guaranteed for exclusive fullscreen or anti-cheat protected titles.
